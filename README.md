# 🍺 주류마블 (여러 폰 버전)

화면이 세 가지로 나뉘어요.

| 화면 | 파일 | 기기 | 하는 일 |
|---|---|---|---|
| 🖥️ 게임판 | `board.html` | 노트북·TV(노트북 연결)·태블릿 | 판·말·주사위·카드를 크게 보여줌. **게임은 여기서 돌아가요** |
| 🎮 진행폰 | `remote.html` → ‘진행폰’ | 진행자 폰 한 대 | 굴리기, 벌주(한 잔) 기록, 확인, 판정 버튼 전부 |
| 📱 플레이어 | `remote.html` → ‘플레이어’ | 각자 폰 | 우리 팀이 누를 버튼만 (비밀 선택은 해당 팀 폰에만) |

- `index.html`: 처음 화면 (게임판 / 폰으로 참가 / 한 폰으로만 하기)
- `jumarble.html`: 한 폰 앱 원본. **게임 내용은 전부 여기에 있어요**
- `board.html`: `jumarble.html` + 연결 기능. `python3 build.py jumarble.html` 로 다시 만들어요 (앱을 고치면 꼭 다시 실행)

## 진행 순서
1. 노트북에서 `board.html`(게임판)을 열고, 팀과 규칙을 정해요.
2. 오른쪽 위 **📡 폰 연결** → 방 코드와 QR이 떠요.
3. 진행자는 QR을 찍고 **🎮 진행폰**, 나머지는 **📱 플레이어 → 우리 팀** 선택.
4. 게임판에서 **게임 시작**. 이후엔 진행폰에서 굴리기·확인을 눌러 진행해요.
   (게임판 화면을 직접 눌러도 돼요)

- 순발력 대결은 공정하게 **진행폰 한 대**로 하고, 10초 멈춰는 **각자 폰에서 직접** 재요 (통신 지연 영향 없음).
- 게임판이 없으면 진행폰에서 `board.html`을 열어 게임판 겸 진행폰으로 써도 돼요.

## 배포 방법 (둘 중 하나)

### A. GitHub Pages + Firebase (추천: 와이파이 상관없이 각자 LTE로)
1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트 만들기 → **Realtime Database** 만들기
2. 데이터베이스 **규칙** 탭에 아래를 붙여넣고 게시
   ```json
   { "rules": { "rooms": { "$room": { ".read": true, ".write": true } } } }
   ```
3. 프로젝트 설정 → **웹 앱 추가** → 나오는 설정값을 `js/config.js` 의 `FIREBASE` 에 붙여넣기 (`TRANSPORT = 'firebase'` 그대로)
4. 이 폴더를 GitHub 저장소에 올리고 → Settings → **Pages** → 브랜치 배포
5. `https://아이디.github.io/저장소/` 를 열면 끝

### B. 노트북을 서버로 (같은 와이파이에서)
1. Node.js 설치 후 이 폴더에서 `npm install` → `npm start`
2. `js/config.js` 의 `TRANSPORT` 를 `'ws'` 로 바꾸기 (또는 주소 뒤에 `?t=ws`)
3. 폰에서 `http://노트북IP:8080` 접속 (윈도우는 `ipconfig` 로 IP 확인, 방화벽 허용)
   - 식당 와이파이가 기기끼리 연결을 막으면 노트북을 폰 핫스팟에 연결하세요

### 테스트 (한 컴퓨터에서)
주소 뒤에 `?t=local` 을 붙이면 같은 브라우저의 탭끼리 연결돼요.
`board.html?t=local` 에서 방을 만들고, 다른 탭에서 `remote.html?t=local&room=코드`.

## 메시지 구조
- 게임판 → 폰: `{t:'state', ...}` 지금 화면 요약 (차례, 팀 현황, 카드, 누를 수 있는 버튼과 그 버튼이 어느 팀 것인지)
- 폰 → 게임판: `{t:'hello'}`, `{t:'cmd', op:'click'|'fill'|'roll'|'pick'|'taxi'|'sw'|'react', ...}`
- 버튼 주인은 앱 코드의 `data-teams` 속성(팀 번호 목록 또는 `host`)으로 정해요. 없으면 그 카드의 참가 팀.

## 🔥 주루마블 불꽃 (11월 16일)
- 주루마블에서 많이 마실수록 말과 팀 카드가 불타올라요. 상한 대비 4단계(🔥~🔥🔥🔥🔥), 3단계부터 카드가 일렁이고 4단계는 크게 타올라요. 단계가 오를 때 "🔥🔥 활활 타오른다!" 같은 알림.
- 폰 화면 팀 현황에도 같은 불꽃 표시. 주루마블의 연승 표시는 ⚡로 바꿔 불꽃과 구분.
- 3D 판에서 불꽃이 잘리지 않게 .tok.fire에 transform-style: preserve-3d.
- 레이아웃 수정: 팀 카드의 🔥가 두 줄로 갈라지던 문제(PC·폰), 600~780px 폭에서 화면이 옆으로 넘치던 문제(html/body overflow-x: clip).
